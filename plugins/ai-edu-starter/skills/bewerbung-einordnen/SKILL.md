# Bewerbung einordnen

Anforderungsprofil und Bewerbungs-Text (CV, Motivationsschreiben):

$ARGUMENTS

Falls Anforderungsprofil fehlt: anfragen. Bewerbung ohne Profil bewerten heisst Bauchgefühl.

## Format

```
# Bewerbungs-Einschätzung: [Name aus CV]

**Bewertet für**: [Stellenbezeichnung]
**Datum**: [DD.MM.YYYY]

## Fit pro Muss-Kriterium

| Muss-Kriterium | Fit | Beleg aus Bewerbung |
|----------------|-----|---------------------|
| [Kriterium 1] | 🟢/🟡/🔴 | "[Zitat oder Verweis]" |
| [Kriterium 2] | | |
| [Kriterium 3] | | |

🟢 klar erfüllt, 🟡 teilweise/unklar, 🔴 fehlt.

## Stärken (aus Bewerbung)

- [konkrete Punkte, mit Zitat oder Verweis]

## Fragezeichen / Lücken

- [Lebenslauf-Lücken > 6 Monate]
- [Wechselrhythmus auffällig kurz]
- [Muss-Kriterien teilweise erfüllt]
- [Referenzen fehlen]

## 5 Interview-Fragen, massgeschneidert

1. [zu einem Muss-Kriterium, das unklar war]
2. [zu einer Lücke im CV]
3. [zu einer Stärke, um sie zu prüfen]
4. [zur Motivation für genau diese Stelle]
5. [Situationsfrage - "wie hätten Sie reagiert, als..."]

## Vorläufige Empfehlung

- **Einladen** / **Absagen** / **Pool-Liste**
- 1-2 Sätze Begründung

## Entwurf Absage (falls Empfehlung Absage)

Wertschätzender Kurzbrief, 4-5 Sätze. Keine Begründung im Detail (diskriminierungs-rechtlich heikel), nur: "Entscheidung getroffen, weitere Kandidat:innen besser gepasst, danke für Interesse, alles Gute".
```

## Regeln

- Deutsch (de-CH), echte Umlaute, Hyphen statt Em-Dash.
- Nichts über die Person annehmen, was nicht im CV / Schreiben steht. Nationalität, Familienstand, Religion, Alter (wenn nicht explizit): ignorieren.
- Bei Diskriminierungs-Risiken im Profil selbst (z.B. Altersangaben): Flag setzen, beim Anforderungsprofil nachjustieren vorschlagen.
- Absagen-Entwurf ohne konkrete Gründe zum Kandidaten. Bei Rückfragen des Kandidaten: "Entscheid interner Abwägung".
- CHF (falls Gehaltserwartung erwähnt) mit Apostroph, Datum DD.MM.YYYY.
- Maximal 1 A4-Seite.
