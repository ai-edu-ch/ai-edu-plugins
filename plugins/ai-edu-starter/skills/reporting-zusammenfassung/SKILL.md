---
description: Verdichtet einen langen Geschäfts- oder Monatsreport (Treuhand, Bank, interne Auswertung) auf eine Management-Summary mit Kennzahlen, Trends und offenen Entscheiden. Einsetzen vor VR-Sitzung oder GL-Review, wenn der Report 10+ Seiten hat.
---

# Reporting-Zusammenfassung

Report-Text (Monats-/Quartals-/Jahresauswertung):

$ARGUMENTS

Falls unklar was für ein Report: kurz nach Typ und Vergleichsperiode fragen. Keine Zahlen erfinden - nur extrahieren.

## Format

```
# Management-Summary: [Reporttitel, Zeitraum]

**Erstellt am**: [DD.MM.YYYY]
**Quelle**: [z.B. Treuhand-Report Juni 2026]

## Kennzahlen

| Kennzahl | Wert | Veränderung vs. Vorperiode |
|----------|------|----------------------------|
| Umsatz | CHF X'XXX'XXX | +/- X% |
| Bruttomarge | X% | |
| EBIT | CHF ... | |
| Liquidität | CHF ... | |
| Debitorenfrist | X Tage | |

## Was hat sich verändert

3-5 Sätze zu den wichtigsten Trends seit Vorperiode. Nur was aus dem Report hervorgeht.

## Entscheide, die anstehen

Genau 3 Entscheide, die der GF oder VR treffen muss, mit Optionen:
1. [Thema] - Optionen: A/B/C
2. ...
3. ...

## Offene Fragen an Treuhand / Buchhaltung

- [wo der Report Lücken hat]
- [wo Vergleichszahlen fehlen]
- [wo eine Annahme unklar ist]
```

## Regeln

- Deutsch (de-CH), echte Umlaute, Hyphen statt Em-Dash.
- CHF-Beträge mit Apostroph, bei > 1 Mio: `CHF 1'250'000` ohne Dezimalstellen ok.
- Prozente mit 1 Dezimalstelle: `+4.2%`, `-1.8%`.
- Datum DD.MM.YYYY.
- **Nichts interpretieren, was nicht im Report steht.** Bei Lücken: "offene Frage" statt Hypothese.
- Entscheide formulieren als Fragen mit echten Optionen, nicht als fertige Empfehlung. GF entscheidet, nicht der Skill.
- One-Pager, maximal 1 A4-Seite.
